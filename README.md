# SEM 3 Result CLI

A tiny command-line project that prints a sample semester result. It uses the npm package [`sem3-marks-tools-aditya`](https://www.npmjs.com/package/sem3-marks-tools-aditya) to calculate each percentage, grade, and the overall average.

## Run it

```bash
npm install
npm start
```

## Package used

The project imports `sem3-marks-tools-aditya@1.0.0` in `index.js` and locks that published version in `package-lock.json`.

- npm package: https://www.npmjs.com/package/sem3-marks-tools-aditya
- Package GitHub repo: https://github.com/AdityaDhinakaran/sem3-marks-tools
